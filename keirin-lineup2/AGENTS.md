# Independent fallback prototype

- Work only inside this project. Do not modify the sibling original site or historical pages.
- Do not relabel K Dreams records or use its odds feed. The actual source must match each record's URL and provider.
- Keep layout, car identities, paired odds views, raw quote precision and source observation times intact.
- Preserve existing stored data. Read or append privately through the already configured Actions connection; never retrieve the credential value, overwrite objects, delete data or configure expiry.
- Validate a complete eligible card, privately archive and read it back before preparing a display artifact. A failed collection or invalid pair leaves the previous artifact intact.
- Never claim a provider permits collection or redistribution merely because a page is readable. Enjoy live extraction has not passed. Keep this a manual prototype until source and operating conditions are verified.
