# keirin-lineup2

既存の `itaingtr/keirin-lineup` と独立した予備サイトです。元のレイアウト・左右2表・合成オッズ・検索を引き継ぎ、トップ・10月22日版・10月21日版では元の映像・ライブボタンを使い、公式ページを同じブラウザータブで開きます。元サイトと過去ページは変更しません。

## 取得元

- 優先候補のエンジョイは、2026-10-22のGitHub Actionsでトップ・出走表ともHTTP 404でした。Web検索で閲覧できることを、自動取得成功とは扱いません。URLの検証・描画は対応しますが、自動収集は未接続です。
- 今回の実働候補はWINTICKETです。ログアウト状態の公開ページ内の `__PRELOADED_STATE__` に含まれる出走表・並び・二車単を読みます。非公開API、ログイン、Kドリームスのデータやフィードには接続しません。
- WINTICKETの選手成績を、同じページの出走表の表示値とも照合します。選手名・期別・直近4か月得点・S/B/逃/捲/差/マは元の数値を保持し、描画時だけ得点を整数表示します。予想印のない選手は空欄です。
- 二車単の順序付き `key: [1,2]` を1着1番・2着2番として扱います。全組合せ・車番・賭式・レースIDを検証し、元の `oddsUpdatedAt` を観測時刻として保ちます。取得失敗を0やnullで埋めません。
- 出走表・並びが欠けた開催は丸ごと除外し、通信や検証に失敗したら既存の表示を保持します。Kドリームスの値を別取得元として付け替えません。

各サイトの公開情報を読めることは、自動取得・保存・転載の一般的な許諾の証明ではありません。今回の確認は独立した試作です。転載権限・収集頻度等の条件を確認せずに無人の一般公開運用へ進めません。記事、写真、予想本文は転載しません。

## 映像・着順の現在の動作

最新のユーザー指示で独自の結果表・動画プレーヤーを外しました。映像・ライブ・着順は通常のリンクと `target="_self"` を使い、ブラウザーの同じタブで公式ページを開きます。ブラウザーの「戻る」で出走表に戻れます。元のボタン表示と公式URLを保ち、着順の `playerIds` も維持します。

リンクは同一サイト内の `/open-web?to=...` を経由し、掲載レース・掲載場に限って通常のHTTP 302で公式HTTPSページへ移動します。アプリ用スキーム・新しいウィンドウ・独自の映像プレーヤーは使いません。リンクを開く処理は外部データを取得せず、データベースの読み書きもしません。端末や公式ページ側のアプリ関連付けまで強制的に無効化できるとは保証しません。

[読み取り専用のHTTP確認](https://github.com/itaingtr/keirin-lineup/actions/runs/39756301093)では、競走成績・ライブともHTTP 200かつ `X-Frame-Options: DENY` でした。そのため公式ページのiframe埋め込みは使いません。この確認や今回の表示修正ではSupabaseへの保存を行っていません。既存データは上書き・削除していません。

以下の古い直接再生・ページ内表示の検証記録は経緯として残します。現在のページは `viewer.js` を読み込まず、`/api/media` を利用しません。

## 今場所の成績

各選手の差・マの下に、WINTICKETの「直近成績 → 今場所」に含まれる前日までの成績を、初日から順に縦に表示します。1日につき「着順＋B」「個人あがり」の2段です。Bはそのレースのバック取得で、上段にある直近4か月の累計Bとは区別します。着順の白丸・黒丸は公式の `displayType`（0=通常、1=白丸、2=黒丸）を維持します。

着順を押すと、公式の競走成績を同じタブで開き、`playerIds` で選んだ選手の緑表示を指定します。保存原本の `result_url` は変えません。補助のリンク先には公式と同じ `?playerIds={選手ID}` を保ちますが、通常のクリックはページ内で処理します。

熊本は2026-10-22開催の初日のため、前日までの今場所成績はありません。空欄に見えないよう「初日」と明示します。9車の並びはスマートフォン幅で間隔を調整し、並び欄で選手や成績を切り落とす `overflow:hidden` を解除しています。

選手IDと氏名、着順、B、個人あがり、事故区分をリンク先の公式結果とも照合済みです。他開催の成績、今日の結果、将来日の結果を混ぜません。初日は「—」、途中参加などで掲載がない日も「—」です。中止などは公式の「未」等を表示し、個人あがりが記録されていない0.0等は「—」と表示します。原本の値は変更しません。小数桁は元の文字列をそのまま保ちます。

`scripts/collect_sources.py` と `scripts/render_races.py` は新規出走表にもこの項目を引き継ぎます。既存出走表に対する追加取得は次の手順です。

```sh
python3 scripts/collect_history.py private-snapshots/new-card.json \
  --snapshot private-snapshots/new-history.json --display /tmp/new-history-display.json
python3 scripts/archive_snapshot.py --date 2026-10-22 \
  --input private-snapshots/new-history.json --report private-snapshots/new-history-usage.json
```

原本は既存Actions接続で非公開に新規追記し、読み戻し後に表示へ反映します。2026-10-22の[実取得・照合](https://github.com/itaingtr/keirin-lineup/actions/runs/39739079219)で、26レース・204人、今場所143成績、リンク先21レース、B取得19件を確認しました。既存の得点・成績・オッズ・コメントの値は保ちます。

## 前日21:00・23:30の翌日分取得

`lineup2-card-nightly.yml` は日本時間21:00と23:30（UTC `0 12 * * *`・`30 14 * * *`）に、翌日分の公開出走表をWINTICKETから取得します。並び・車番・氏名・得点・S/B/決まり手・AI印・前日までの今場所成績を検証します。並び未発表の開催は丸ごと除外し、通信・検証失敗や掲載可能レースがゼロの場合は公開中のページを保ちます。開始が日付をまたいでも、予定していた取得時刻を基準に対象日を決めます。

夜はオッズを解析・収集しません。二車単は公開中の出走表マニフェストを使い、そのレース当日の09:00〜20:00 JSTだけ取得します。夜に翌日分へ切り替えた後、前日や未来日のオッズを取り込むことはありません。

取得結果のうち表示項目だけを `odds-diagnostics/fallback/cards/YYYYMMDD/runs/run-ID-attempt.json` に新規追記します。過去の実行ファイル・既存データは保持し、SHA-256付きの当日索引とトップ用索引を同じcommitで更新します。Supabaseへの追加保存、原本HTMLの保存、コメントのコピーは行いません。GitHub Actionsの既存トークンで実行し、Siteの公開用資格情報をActionsへ保存する必要はありません。

公開SiteのWorkerは検証済み索引とチェックサムが一致する表示データを読み、トップと `lineYYYYMMDD.html` に同じHTMLを返します。夜ごとの再デプロイ操作は不要です。過去ページは保持し、新規の日付にも同じタブで開く公式ページへのリンクを使います。読み出しに失敗した場合は直前に検証した表示を保ち、初回アクセスで配信元に接続できない場合はデプロイに含まれる出走表を表示します。索引のキャッシュは最大60秒です。

スケジュールは既定ブランチmainに、実装は `keirin-lineup2-enjoy` に配置します。本サイトのページ・取得処理・Supabase設定は変更しません。手動実行の日付は空欄なら翌日です。過去日や当日09:00以降の再公開は拒否します。コードpush時は当日09:00前だけ同日の実データで公開確認し、それ以外はプレビューを追記して公開中の索引を保ちます。
